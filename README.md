# 🌱 HobbyMate

> **나에게 맞는 취미를 발견하고, AI 맞춤 로드맵으로 꾸준히 성장하는 취미 학습 Android 앱**

## 📌 프로젝트 소개

HobbyMate는 새로운 취미를 시작하고 싶지만 무엇을 선택해야 할지, 어떻게 배워야 할지 막막한 사용자를 위한 취미 학습 서비스입니다.

사용자의 성향을 분석해 적합한 취미를 추천하고, 목표와 학습 가능 시간에 맞춘 로드맵을 생성합니다. YouTube 학습 영상, 단계별 체크리스트, 일일 기록과 주간 회고를 통해 취미 탐색부터 지속적인 실천까지 하나의 앱에서 관리할 수 있습니다.

## 💡 문제 정의

새로운 취미를 시작하려는 사용자는 다음과 같은 어려움을 겪습니다.

- 자신에게 어떤 취미가 잘 맞는지 판단하기 어렵습니다.
- 취미를 선택해도 무엇부터 배워야 하는지 알기 어렵습니다.
- 온라인 학습 자료가 너무 많아 적절한 영상을 찾는 데 시간이 걸립니다.
- 명확한 계획과 기록 수단이 없어 취미 활동을 꾸준히 이어가기 어렵습니다.
- 자신의 성장 과정과 결과물을 한눈에 확인하기 어렵습니다.

HobbyMate는 **취미 추천 → 목표 설정 → AI 로드맵 생성 → 영상 기반 실습 → 활동 기록 → 주간 회고**의 흐름을 제공해 이러한 문제를 해결합니다.

## ✨ 주요 기능

### 1. 🧭 취미 성향 진단

온보딩 질문을 통해 활동 장소, 선호 방식, 예산, 학습 성향 등을 파악합니다.

### 2. 🎯 맞춤 취미 추천

사용자의 답변을 분석해 적합한 취미와 일치도를 제공하고, 예상 비용·난이도·준비물 등 상세 정보를 보여줍니다.

### 3. 🗺️ AI 맞춤 로드맵 생성

현재 수준, 목표, 학습 기간, 주당 횟수와 회당 시간을 반영해 단계별 학습 로드맵을 생성합니다.

### 4. ▶️ YouTube 학습 영상 추천

로드맵의 주차별 주제에 맞는 영상을 YouTube Data API로 검색하고 앱 안에서 선택·재생할 수 있습니다.

### 5. ✅ AI 실습 체크리스트

선택한 영상의 제목과 설명을 AI가 분석해 사용자가 직접 따라 할 수 있는 단계별 실습 체크리스트를 제공합니다.

### 6. 📝 일일 활동 기록

실제 활동 시간, 만족도, 메모, 완료 단계와 결과 사진을 저장합니다. 완료하지 못한 단계는 다음 학습으로 이어갈 수 있습니다.

### 7. 📊 진행률 및 주간 회고

주간 학습 일수, 총 학습 시간, 목표 달성률을 계산하고 처음과 최근의 결과 사진을 비교해 성장 과정을 확인합니다.

### 8. 🏠 통합 홈 화면

현재 진행 중인 취미, 로드맵 주차, 오늘의 목표와 전체 진행률을 한눈에 확인합니다.

## 🛠️ 기술 스택

| 구분 | 기술 | 활용 내용 |
| --- | --- | --- |
| Language | **Kotlin** | Android 앱 및 비즈니스 로직 구현 |
| Local DB | **SQLite · Room** | 사용자, 취미, 로드맵, 세션, 체크리스트, 리뷰 저장 |
| Design | **Figma** | 화면 설계, 사용자 흐름 및 UI 시안 제작 |
| Version Control | **Git** | 변경 이력 관리 및 협업 |

## 🗄️ 데이터베이스

Android 내부 SQLite를 직접 다루는 대신 공식 추상화 라이브러리인 **Room**을 사용합니다. 앱 데이터는 사용자의 기기 내부에 저장됩니다.

주요 저장 데이터는 다음과 같습니다.

- 사용자 및 온보딩 답변
- 취미 목록과 사용자가 선택한 취미
- AI가 생성한 가이드와 주차별 로드맵
- 추천 영상과 일일 학습 세션
- 체크리스트 수행 상태
- 일일·주간 리뷰와 결과 사진 경로

DAO와 Repository 계층을 통해 데이터를 관리하며, 여러 데이터를 함께 저장해야 하는 작업에는 트랜잭션을 적용합니다.

## 🚨 오류사항 대응

| 오류 상황 | 대응 방식 |
| --- | --- |
| YouTube API 키 누락 | 전용 예외를 발생시키고 `local.properties` 설정 안내 표시 |
| 인터넷 연결 실패 | 호스트 연결 오류를 구분해 네트워크 확인 메시지 표시 |
| OpenAI 프록시 연결 실패 | 분석 서버 연결 안내와 재시도 버튼 제공 |
| 서버 응답 지연 | 타임아웃 오류를 구분해 잠시 후 재시도하도록 안내 |
| YouTube 요청 오류 | HTTP 400·403 및 기타 상태 코드를 구분해 원인 표시 |
| OpenAI 인증 실패 | HTTP 401 응답 시 API 키 확인 안내 |
| OpenAI 사용량 초과 | HTTP 429 응답 시 사용 한도 안내 |
| 서버 API 키 미설정 | HTTP 503 응답 시 서버 환경 변수 설정 안내 |
| 검색 결과 없음 | 빈 상태 메시지와 영상 다시 불러오기 기능 제공 |
| AI 응답 형식 오류 | JSON 파싱 및 로드맵 검증 실패를 전용 예외로 변환 |
| 리뷰 저장 실패 | 오류 메시지를 표시하고 입력 내용을 유지해 재시도 지원 |
| 이미지 로딩 실패 | 기본 배경 이미지를 표시해 화면 깨짐 방지 |

## 🛡️ 예외처리

### 입력값 검증

- 목표가 비어 있거나 학습 기간이 유효하지 않으면 다음 단계로 이동하지 않습니다.
- 리뷰 제목과 실제 활동 시간을 검사하고 잘못된 입력란에 오류 메시지를 표시합니다.
- YouTube 검색 결과 수는 API 허용 범위 안으로 제한합니다.
- 서버에서 영상 분석·로드맵 요청에 필요한 값이 없으면 `400 Bad Request`를 반환합니다.
- 요청 본문이 제한 크기를 초과하면 `413 Payload Too Large`를 반환합니다.

### 네트워크 예외

- `UnknownHostException`, `ConnectException`, `SocketTimeoutException`을 구분해 사용자 친화적인 메시지로 변환합니다.
- Retrofit의 `HttpException` 상태 코드에 따라 인증, 사용량, 설정 오류를 구분합니다.
- 실패 상태를 ViewModel의 UI State로 전달해 화면에 오류 메시지와 재시도 버튼을 표시합니다.

### 데이터 및 AI 응답 예외

- 비어 있거나 규격에 맞지 않는 AI 로드맵 응답은 `InvalidRoadmapResponseException`으로 처리합니다.
- 영상 분석 체크리스트의 최소 단계 수를 검증합니다.
- 알 수 없는 취미 카테고리는 기본 `ETC` 카테고리로 변환해 앱 종료를 방지합니다.
- 중요하지 않은 캐시·보조 데이터 저장 실패는 핵심 사용자 흐름을 중단하지 않도록 분리합니다.
- 리뷰 저장 결과는 성공과 실패 상태로 나누어 중복 요청을 방지합니다.

### 서버 예외

- OpenAI API 오류의 HTTP 상태와 메시지를 Android 앱에 전달합니다.
- 처리되지 않은 오류는 공통 오류 응답으로 변환해 서버가 비정상 종료되지 않도록 합니다.
- OpenAI API 키는 Android 앱에 포함하지 않고 Node.js 프록시 서버의 환경 변수로 관리합니다.
